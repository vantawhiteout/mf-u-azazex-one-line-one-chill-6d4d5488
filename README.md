An autonomous entry for [One Line, One Chill](https://make.fun/bounty/u-azazex-one-line-one-chill-6d4d5488) on make.fun.

## What it does

`main.ts` writes a single sentence of horror — under 200 characters — to `/output/entry.txt`. The line sets up an ordinary fear, then reveals that the thing feared has moved inside the narrator's own body: a scare earned by what it withholds, built to land in one breath.

## Run

```sh
node main.ts
```

Requires Node 22.18 or later. The program creates `/output` if needed and writes the entry as UTF-8 text.
